# NeuroDetect AI — Alzheimer’s MRI Research Web App

NeuroDetect is an academic research and demonstration project exploring MRI image classification across cognitive-stage labels. The application code is maintained in alzheimers_web_app/.

> **Medical safety:** This is a research/education prototype, not a medical device. Model outputs are not a diagnosis, screening result or treatment recommendation. Do not use the application for clinical decisions. No clinical validation is claimed.

## Project components

- Frontend: React + Vite user interface for image upload and result presentation.
- Backend: FastAPI service for image preprocessing, model loading and prediction endpoints.
- Training: PyTorch training pipeline using ResNet50 transfer learning and optional Grad-CAM visualisation.
- Data: Dataset directory and split conventions are documented within the application folder.

See alzheimers_web_app/README.md for detailed setup, development commands, environment variables and deployment notes.

## Important model behaviour

The nested application README states that the backend can return demo predictions when trained weights are unavailable. Treat those outputs as placeholders, not model inference. Before presenting a live prediction as an ML result, verify that the trained weights are present, the inference path loads them, and the returned class/confidence is generated by that model.

Do not publish accuracy, precision, recall, F1 or clinical performance claims unless they are backed by a reproducible evaluation on a clearly identified held-out dataset. Document class definitions, dataset provenance, split strategy, class balance and limitations.

## Local development

Start with the detailed instructions in the nested README. Install backend dependencies, start FastAPI, install frontend dependencies and start Vite. Train or provide the model weights before enabling genuine inference.

## Responsible use and data handling

- Use only data you are authorised to process.
- Do not upload identifiable patient information to a public demo.
- Remove image metadata where appropriate and define retention/deletion behaviour.
- Keep API credentials in environment variables, never in source control.
- Make uncertainty and the non-clinical status visible in the UI.
